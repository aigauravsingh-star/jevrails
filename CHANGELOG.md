# Changelog

## 0.1.0

- Initial alpha release.
- Added hybrid guard engine with local deterministic checks and pluggable decision backend.
- Added Jev-compatible HTTP backend.
- Added CLI scan and eval commands.
- Added OpenAI-compatible wrapper, LLM Guard-style scanner adapter, and optional FastAPI middleware.
- Added tests for core blocking, redaction, failure behavior, and integrations.
